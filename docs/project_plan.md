# Project Plan

## Goal
Build an AI-powered weekly social media marketing assistant for solo founders that can generate ideas, draft posts, and support lightweight planning.

## Current Phase
- Basic Python app shell
- AI content generation utility
- Simple workflow abstraction
- SQLite storage layer
- Simple content calendar model
- Testing for core prompt logic

## Next Steps
1. Add real OpenAI integration for generating content variations.
2. Expand prompt frameworks for LinkedIn, X, and Instagram.
3. Create a dashboard UI with a weekly content calendar.
4. Add OAuth or authentication for founder accounts.
5. Add scheduling and publishing support.

## Tech Stack
- Python
- SQLite
- OpenAI API
- dotenv
- pytest
