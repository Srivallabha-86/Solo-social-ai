# Project Plan

## Goal
Build a production-ready AI social marketing application for solo founders with a scalable service-oriented structure.

## Current state
- FastAPI application shell
- Config-driven environment management
- Route-based API structure
- Service layer for content generation and calendar planning
- Database model for storing content ideas
- Test scaffolding for health checks and application startup

## Next steps
1. Add Postgres support for production deployments.
2. Implement migrations and ORM tables for marketing campaigns.
3. Add user auth, team permissions, and scheduling features.
4. Integrate external publishing APIs for LinkedIn, X, and Instagram.
5. Add observability, metrics, and background job processing.
